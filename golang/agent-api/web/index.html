Primary Network

Avalanche is a heterogeneous network of blockchains. The Primary Network is a special Avalanche L1 that runs three chains.

Unlike homogeneous networks, where every application lives on one chain, Avalanche lets separate chains be created for different applications. Avalanche Mainnet is the Primary Network plus every deployed Avalanche L1. A node can become a Primary Network validator by staking at least 2,000 AVAX.

Architecture

Avalanche is a heterogeneous network of blockchains. The Primary Network is a special Avalanche L1 that runs three blockchains: the Contract Chain (C-Chain), the Platform Chain (P-Chain), and the Exchange Chain (X-Chain). Avalanche Mainnet is comprised of the Primary Network and all deployed Avalanche L1s.

A node can become a validator for the Primary Network by staking at least 2,000 AVAX.

C-Chain (Contract Chain)

The C-Chain is an implementation of the Ethereum Virtual Machine (EVM). Its API supports Geth’s API and the deployment and execution of smart contracts written in Solidity. The C-Chain is an instance of the Coreth Virtual Machine.

P-Chain (Platform Chain)

The P-Chain is responsible for all validator and Avalanche L1-level operations. The P-Chain API supports creating new blockchains and Avalanche L1s, adding validators, staking, and other platform-level operations. It is an instance of the Platform Virtual Machine.

X-Chain (Exchange Chain)

The X-Chain is responsible for operations on digital smart assets known as Avalanche Native Tokens. A smart asset can represent a real-world resource (for example, equity or a bond) with rules that govern its behavior, like “can’t be traded until tomorrow.” One asset traded on the X-Chain is AVAX. When you issue a transaction on Avalanche, you pay a fee denominated in AVAX. The X-Chain is an instance of the Avalanche Virtual Machine (AVM).
